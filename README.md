# Zorentiva ShopSphere — Luxury Fashion Store Demo

A responsive, frontend-only luxury fashion e-commerce concept created for the Zorentiva Technologies portfolio.

## Features
- Luxury editorial storefront with responsive layout
- Product catalogue with category filters
- Add-to-bag interactions and quantity controls
- Shopping bag drawer with subtotal calculation
- Simulated checkout form and confirmation screen
- Mobile navigation and responsive product grid

## Run locally
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and remote Unsplash product photography.

## Deploy to GitHub Pages
1. Create a **public** GitHub repository named `zorentiva-shopsphere-demo`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. The expected URL is:
   `https://zorentivatech.github.io/zorentiva-shopsphere-demo/`

## Demo limitations
- Product names, descriptions, images, and prices are illustrative sample content.
- Checkout is simulated only. It does not process payments, save customer details, create real orders, or connect to inventory.
- No backend, database, authentication, shipping integration, or payment gateway is included.
- Replace sample products and imagery before using this for a real business.

## Portfolio presentation
Describe this project as a **concept storefront / frontend demo**, not as a completed client engagement.
